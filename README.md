## О проекте

Рекурсивная функция вызывает саму себя для решения более простых подзадач. У каждого рекурсивного алгоритма есть база рекурсии, которая решается напрямую, и декомпозиция, которая сводит задачу к задачам меньшего размера. Приложение делает эту работу видимой.

Для каждого алгоритма программа:

1. Выполняет его на введённых пользователем данных;
2. Записывает каждый вход в функцию и каждый возврат из неё;
3. Показывает дерево вызовов, число вызовов и глубину рекурсии, график и таблицу хода выполнения;
4. Измеряет время работы и накладывает на график теоретическую кривую c·f(n), подобранную методом наименьших квадратов.

## Возможности

- **Пять вкладок:** рекурсивные алгоритмы, фрактал, ханойские башни, дерево вызовов, замеры времени.
- **Три рекурсивных алгоритма** с графиком, наглядной схемой, таблицей хода выполнения и карточкой описания (сложность, память, база рекурсии, декомпозиция).
- **Фрактал «ковёр Серпинского»:** глубина от 0 до 5, число вызовов и вырезанных квадратов выводится рядом с кнопкой.
- **Ханойские башни:** решение рекурсией и через стек, автоматический и пошаговый режимы, кнопки «Вперёд» и «Назад», регулировка задержки, лог ходов с сохранением в файл.
- **Дерево рекурсивных вызовов** для степени, перевода в двоичную систему, подмножеств и ханойских башен с просмотром выполнения по шагам вперёд и назад.
- **Настраиваемый эксперимент:** максимальный размер N max, шаг по n, количество запусков.
- **Среднее время и стандартное отклонение** по всем запускам для каждой точки.
- **Трёхмерный график замеров**, который можно вращать мышью: ось X - n, ось Y - среднее время, ось Z - стандартное отклонение.
- **Подписи осей с единицами:** единица времени (нс, мкс, мс) подбирается автоматически.

## Реализованные алгоритмы

### Часть I. Рекурсивные алгоритмы

| Алгоритм | Идея | Сложность |
|---|---|:---:|
| Быстрое возведение в степень | aⁿ = (a·a)^(n/2) при чётном n, aⁿ = a·aⁿ⁻¹ при нечётном | O(log n) |
| Перевод в двоичную систему | bin(n) = bin(n / 2) + (n mod 2) | O(log n) |
| Все подмножества | каждый элемент либо не берём, либо берём | O(n·2ⁿ) |

### Задание 1. Фрактал

| Алгоритм | Идея | Сложность |
|---|---|:---:|
| Ковёр Серпинского | квадрат делится на 9 частей, центральная вырезается, для 8 остальных повторяем | O(8ᵈ) |

### Задание 2. Ханойские башни

| Алгоритм | Идея | Сложность |
|---|---|:---:|
| Рекурсия | n - 1 колец на вспомогательный стержень, самое большое на нужный, n - 1 колец сверху | O(2ⁿ) |
| Стек (дополнительное задание) | подзадачи хранятся в явном стеке вместо стека вызовов | O(2ⁿ) |

Минимальное число ходов равно 2ⁿ - 1. Оба метода строят одну и ту же последовательность ходов.

## Дерево рекурсивных вызовов

Для каждого алгоритма написана «трассирующая» версия. Она делает то же самое, что и обычная функция, но при входе и при выходе сообщает об этом классу `CallTree`. Основные алгоритмы от записи вызовов не зависят, поэтому замеры времени не искажаются.

- Каждый вызов - узел дерева: номер, глубина, текст вызова и результат.
- Выполнение алгоритма - список шагов «вход» и «возврат». Для n вызовов получается ровно 2n шагов.
- Цвета узлов: **серый** - ещё не вызывался, **синий** - вызов начался, **зелёный** - вызов закончился (с результатом). Текущий шаг выделен оранжевой рамкой.

## Методика измерений

Для каждого значения n = шаг, 2·шаг, …, N max выполняется заданное число запусков:

1. **Подготовка данных** - массив элементов для подмножеств и контейнеры результата создаются до запуска таймера и в замер не входят.
2. **Замер** - `System.Diagnostics.Stopwatch` измеряет только работу алгоритма.
3. **Повторы для быстрых алгоритмов** - алгоритм запускается пачками 1, 2, 4, 8, … раз, пока суммарное время не достигнет 5 мс. Итоговое время делится на число запусков. Это нужно, потому что время одного вызова меньше разрешения таймера. Размер пачки ограничен значением 2²⁰.
4. **Результат не пропадает** - результат каждого запуска суммируется в служебную переменную, чтобы компилятор не удалил вычисления как бесполезные.
5. **Статистика** - по всем запускам вычисляются среднее время и стандартное отклонение.

Коэффициент теоретической кривой c·f(n) подбирается методом наименьших квадратов:

$$
c = \frac{\sum_i f(n_i)\, T_i}{\sum_i f(n_i)^2}
$$

где $T_i$ - измеренное время для $n_i$, а $f(n)$ - функция из оценки сложности: log₂ n, n·2ⁿ или 2ⁿ.

Ограничения: число точек на графике не больше 300, а для подмножеств и ханойских башен N max не больше 22.

> [!TIP]
> Для корректных замеров запускайте приложение в конфигурации **Release**: в Debug оптимизации компилятора отключены и результаты содержат больше шума.

## Запуск

**Требования:** Windows 10 или 11, [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

Через IDE (JetBrains Rider или Visual Studio):

1. Клонировать репозиторий.
2. Открыть `Lab2.sln`.
3. Выбрать конфигурацию **Release** и запустить проект.

Через командную строку:

```bash
git clone <ссылка на репозиторий>
cd <папка репозитория>
dotnet run -c Release --project RecursionApp/RecursionApp.csproj
```
